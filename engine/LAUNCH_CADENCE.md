## Reglas

| Regla | Valor |
|---|---|
| Productos por sprint | **2 productos** |
| Duración por sprint | **7 días** |
| Score mínimo para lanzar | **80/100** |
| Tiempo de campaña por producto | **14 días** (2 sprints) |
| R&D ideas por sprint | **Descubrir 10, matar las malas, INVEST 1-2** |
| Productos en pipeline activo | **Máximo 4** (2 launched + 2 building) |

## Estados de Producto

```
IDEA → VALIDATE → MVP_BUILD → SCORE_CHECK → LAUNCH → CAMPAIGN → MONETIZE
  ↑ R&D        ↑ R&D       ↑ Engine     ↑ Prod Eng  ↑ Creative ↑ Autopilot
  2 días       1 día       3-5 días     Check ≥80   Agent      Pipeline
```
