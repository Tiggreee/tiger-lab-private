# Code And Doc Standards

## Código
- Preferir cambios pequeños y reversibles.
- No romper contratos públicos sin versión.
- Incluir tests para comportamientos críticos.
- Evitar complejidad accidental.

## Documentación
- Todo documento crítico tiene owner y fecha.
- Escribir directo, sin ambigüedad.
- Usar ejemplos concretos cuando aplique.
- Mantener enlaces cruzados a decisiones fuente.

## Convenciones
- ADRs en `02-architecture/adr/`.
- SOPs en `05-operations/`.
- Memoria institucional en `08-memory/`.
