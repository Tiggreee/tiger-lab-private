# Agent Operating Rules

## Objetivo
Alinear agentes para actuar con contexto consistente.

## Reglas transversales
- Leer fuentes primarias antes de proponer cambios.
- Priorizar seguridad, trazabilidad y reversibilidad.
- Declarar supuestos cuando falte información.
- No sobreescribir decisiones aceptadas sin ADR nuevo.

## Estándar de respuesta de agentes
1. Resultado propuesto.
2. Riesgos y límites.
3. Archivos de contexto impactados.
4. Próximo paso operativo.

## Escalamiento
- Conflicto estratégico: escalar a Product Architect.
- Conflicto técnico mayor: escalar a Engineering Lead.
- Incidente operacional: activar `05-operations/INCIDENT_PLAYBOOK.md`.
