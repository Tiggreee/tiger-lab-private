# System Overview

## Mapa de dominios
- Captura de leads.
- Orquestación de bots.
- Monetización y pricing.
- Publicación de contenido.
- Observabilidad y command center.

## Flujo lógico
1. Entrada de tráfico.
2. Captura de eventos y leads.
3. Enriquecimiento y scoring.
4. Activación de bots.
5. Conversión y seguimiento.
6. Reporte de métricas.

## Decisiones clave
- Event-first para trazabilidad.
- Contratos explícitos entre bots.
- Contexto central como dependencia transversal.
