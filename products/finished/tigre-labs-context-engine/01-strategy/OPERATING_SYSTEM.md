# Operating System

## Rituales
- Daily 20 min: estado operativo + bloqueos.
- Weekly 60 min: revisión de KPIs + decisiones.
- Monthly 90 min: estrategia + capacidad + foco.

## Ciclo de ejecución
1. Definir hipótesis.
2. Ejecutar experimento.
3. Medir resultado.
4. Documentar aprendizaje.
5. Actualizar plan/contexto.

## Políticas
- Sin métrica definida no hay iniciativa priorizada.
- Todo experimento tiene owner y fecha de evaluación.
- Lo que cambia producción actualiza playbook.
