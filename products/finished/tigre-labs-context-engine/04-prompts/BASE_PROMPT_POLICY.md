# Base Prompt Policy

## Principios
- Claridad de objetivo.
- Restricciones explícitas.
- Criterios de calidad verificables.
- Formato de salida estable.

## Plantilla mínima
- Contexto relevante.
- Tarea exacta.
- Restricciones.
- Formato de entrega.
- Criterio de éxito.

## Control de cambios
- Registrar fecha, owner y motivo.
- Indicar impacto esperado en calidad/latencia/costo.
- Mantener historial de versiones.
