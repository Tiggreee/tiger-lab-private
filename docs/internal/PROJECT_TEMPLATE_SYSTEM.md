# Internal Template System

## Available Templates
- `node-api`: Minimal backend service.
- `react-vite`: Frontend starter stub.

## Create New Project
- Bash: `./scripts/new-project.sh my-service node-api`
- PowerShell: `./scripts/new-project.ps1 -Name my-service -Template node-api`

## Add New Template
1. Create folder under `templates/<template-name>`.
2. Add README and runnable baseline.
3. Document usage in this file.
