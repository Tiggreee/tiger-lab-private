# Offer Catalog

## Offer 1: Full Stack MVP Sprint (2 weeks)
- Target client: Small business with manual operations.
- Deliverables:
  - MVP web app with auth and dashboard.
  - API with basic security hardening.
  - Deploy to production with rollback notes.
- Price range: 1200 to 2500 USD fixed.
- Upsell:
  - Monthly maintenance retainer.
  - Analytics and conversion optimization.

## Offer 2: API Foundation and DevOps Setup (10 days)
- Target client: Teams with unstable backend delivery.
- Deliverables:
  - REST API baseline with auth, validation, and logs.
  - CI pipeline with tests and security checks.
  - Staging environment and release checklist.
- Price range: 900 to 1800 USD fixed.
- Upsell:
  - SLO monitoring package.
  - Incident response playbook.

## Offer 3: AI Productivity Assistant (3 weeks)
- Target client: Founder-led teams drowning in repetitive tasks.
- Deliverables:
  - AI workflow for summaries, reports, and task extraction.
  - Basic evaluation harness.
  - Cost controls for model usage.
- Price range: 1500 to 3500 USD fixed.
- Upsell:
  - Monthly prompt optimization.
  - Team onboarding and process automation.

## Offer 4: Security Hardening and Audit Lite (1 week)
- Target client: Apps with poor security baseline.
- Deliverables:
  - Secret hygiene and dependency risk review.
  - Rate-limit, headers, CORS policy, and auth checks.
  - Actionable remediation report.
- Price range: 600 to 1400 USD fixed.
- Upsell:
  - Quarterly re-audit.
  - Managed patch cadence.

## Packaging Rules
- Always include measurable outcomes:
  - Time saved per week.
  - Revenue uplift proxy.
  - Error rate reduction.
- Never sell code only. Sell business outcomes plus technical delivery.
- Keep at least one low-ticket, one mid-ticket, and one premium offer active.
