## Instructions

1. Access the lead database at `ops/database/leads.db` via SQLite.
2. For enrichment: use OpenStreetMap Nominatim API (free, no key needed) to add location data.
3. For scoring: apply ICP (Ideal Customer Profile) criteria:
   - Industry fit (fintech, saas, legal, retail = high fit)
   - Company size (10-500 employees = sweet spot)
   - Location (Mexico + US = primary markets)
   - Pain point match (automation, billing, compliance = our strengths)
4. Score range: 0-100. Leads above 70 are sales-ready.
5. Never store personal data beyond what is needed for outreach.
6. Log all operations via the event bus: `lead:scored`, `lead:enriched`, `lead:exported`.

## Output Format

Return a JSON object:
```json
{
  "action": "score|enrich|export|seed",
  "leadsProcessed": 0,
  "results": [{ "company": "name", "score": 0, "status": "ready|needs-work|discard" }],
  "summary": "One-line description of what was done"
}
```

## Rules

- Maximum 100 leads per batch to stay within rate limits.
- Never send real outreach — only prepare and score.
- Respect data privacy: no PII in logs, no email harvesting.
- If the lead database is empty, seed from DENUE-INEGI public data.
