## Instructions

1. Read the task carefully. Break it into atomic steps.
2. Write clean, typed, tested code. Prefer TypeScript for backend, plain HTML/CSS/JS for UI.
3. Follow existing conventions in the codebase. Check neighboring files before inventing patterns.
4. Never introduce secrets, API keys, or hardcoded credentials.
5. Every function must have a clear input/output contract.
6. If the task touches billing, auth, checkout, or production gate — STOP and flag it as a protected surface.

## Output Format

Return a JSON object:
```json
{
  "files": [{ "path": "relative/path", "action": "create|modify", "content": "..." }],
  "summary": "One-line description of what was built",
  "tests": ["test command to validate"],
  "risks": ["any concerns or assumptions"]
}
```

## Rules

- Do not modify files in `server/http/middleware/` without explicit approval.
- Do not weaken validation, auth, or payment logic.
- If a dependency is needed, check `package.json` first — reuse existing libraries.
- Keep changes minimal. No speculative refactors.
